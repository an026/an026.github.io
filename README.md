# allisonvu.org

Personal portfolio site — Next.js (static export), deployed to GitHub Pages
at [allisonvu.org](https://allisonvu.org), backed by [Supabase](https://supabase.com)
for content (posts, projects, work history) and the `/admin` dashboard.

See **[SETUP.md](./SETUP.md)** to configure Supabase and deploy.

## Local development

```
npm install
cp .env.example .env.local   # fill in your Supabase URL/keys, see SETUP.md
npm run dev
```
